What's the #1 conversion action on each site?

Every great landing page is built around one primary CTA. What do you want visitors to do?

A

Book a Demo

Sales-led motion. Visitor schedules a call with you. Best for brokerage sales (high ACV). The old site used this — it works when the buyer needs to be sold.

B

Start Free Trial / Sign Up

Product-led motion. Visitor creates an account and tries the app directly. Best for individual agents — low friction, self-serve, viral potential.

C

Two CTAs — Demo for brokerages, Sign Up for agents

Different CTA per audience. Since we're making 3 versions anyway, we can optimize each one differently. Most work but highest conversion potential.
